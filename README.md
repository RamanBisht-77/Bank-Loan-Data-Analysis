# Bank Loan Analysis Dashboard

## Project Overview

This project analyzes bank loan data to understand loan applications, funded amounts, received amounts, loan performance, and borrower characteristics.

The project uses **Excel, SQL, and Power BI** to perform data analysis, validate key metrics, and create interactive dashboards.

## Tools & Technologies

- Excel
- SQL
- Power BI
- DAX
- Data Analysis
- Data Visualization

## Data Workflow

Excel Dataset
→ SQL Data Analysis & Validation
→ Power BI
→ DAX Measures
→ Interactive Dashboard

## Key Analysis

The project includes analysis of:

- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average Debt-to-Income Ratio (DTI)
- Month-to-Date (MTD) Analysis
- Month-over-Month (MoM) Analysis
- Good Loan vs Bad Loan Analysis
- Loan Status Analysis
- Monthly Loan Trends
- State-wise Loan Analysis
- Loan Term Analysis
- Employment Length Analysis
- Loan Purpose Analysis
- Home Ownership Analysis
